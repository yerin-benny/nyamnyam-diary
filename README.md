# 냠냠 다이어리

집 / 데이트 식비를 나눠 기록하는 가계부 웹앱입니다.

## 기능
- 집 · 데이트 구분 기록, 품목별 금액 입력
- 영수증·음식 사진 첨부 (claude.ai 아티팩트에서 열면 AI가 품목·금액을 자동으로 채움)
- 영수증 여러 장 한 번에 올려서 초안 일괄 생성
- 주간 · 월간 통계 (요일/주차별 그래프, 카테고리 비율, 지난 기간 대비)
- 월 달력 뷰, 월 예산 진행률
- 맛 평가(별점) · 재방문 여부, "또 가고 싶은 곳" 목록
- 데이트 정산 (누가 냈는지 기록 → 차액 계산)
- CSV 내보내기

## 파일
- `index.html` — 단독으로 열리는 버전. GitHub Pages나 브라우저에서 바로 열 수 있습니다.
  이 경우 기록은 브라우저의 localStorage에 저장되고, AI 영수증 분석은 사용할 수 없습니다.
- `src/nyamnyam-diary.html` — claude.ai 아티팩트 원본. claude.ai에 게시하면 계정 저장소 동기화와 AI 분석이 동작합니다.

## 로컬 실행
`index.html`을 브라우저로 열면 됩니다. 별도 빌드가 없습니다.
